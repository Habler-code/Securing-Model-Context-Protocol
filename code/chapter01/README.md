# Chapter 1 — Understand MCP trust boundaries

The current chapter is conceptual. It traces initialization, discovery, Tool
invocation, policy decisions/enforcement and the differences between stdio and
Streamable HTTP. It contains diagrams and worked explanations, not a runnable
code listing. It requires no MCP server, SDK, cloud account or credential.

The first runnable policy gate is the Python example in Chapter 2. The later
chapter folders implement the controls introduced here.
